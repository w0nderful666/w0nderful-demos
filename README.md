**[https://w0nderful666.github.io/w0nderful-demos/](https://w0nderful666.github.io/w0nderful-demos/)**

## 📦 Demos

| Demo | Description | Technologies |

## ✨ Features

- **3D Starfield Background** - Three.js powered with 2000+ stars and floating particles
- **4 Theme System** - Apple, Microsoft, Material Design, and Linux themes
- **Smooth Animations** - GSAP ScrollTrigger powered reveal animations
- **Interactive Effects** - Custom cursor, click particles, card tilt effects
- **Responsive Design** - Works on all devices
- **Performance Optimized** - Throttled scroll events, requestAnimationFrame

## 🎨 Themes

Switch between 4 carefully crafted themes:

1. **Apple** - Clean, minimal design with rounded corners
2. **Microsoft** - Fluent Design with Segoe UI typography
3. **Material Design** - Elevation shadows and uppercase buttons
4. **Linux** - Terminal green with monospace fonts and scanlines

## 🛠️ Adding New Demos

1. Create a new directory under `demos/`
2. Add your demo files
3. Update the homepage `index.html` to include the new demo card
4. Push to main branch
